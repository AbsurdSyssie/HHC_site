# Security Policy

## Reporting a vulnerability

Do not report suspected vulnerabilities through public issues.

Report them privately through [GitHub's private vulnerability reporting](https://github.com/pacharanero/open-gp-practice-website/security/advisories/new) for this repository.

Include a description of the issue and its impact, the affected commit, safe reproduction steps, and any suggested fix. Do not include credentials or any patient-identifiable information.

This is a volunteer-maintained project. We aim to acknowledge reports within 5 working days.

## Scope

This policy covers the template in this repository. If you find a problem with a particular practice's website, contact that practice. Report problems in NHS.UK frontend to [NHS England](https://github.com/nhsuk/nhsuk-frontend), and tell us privately if they affect this template.

## Safety-relevant reports

If the issue could affect patient safety, for example by hiding urgent help, showing the wrong contact details, or letting untrusted code run on a practice's site, say so clearly. We will treat it as both a security finding and a potential clinical safety hazard, and record it in the [hazard log](docs/clinical-safety/hazard-log.md).

## Disclosure

We use coordinated disclosure. Because each practice hosts its own copy, a fix only reaches practices when they update. After a fix is available we will publish an advisory explaining how practices can update.
