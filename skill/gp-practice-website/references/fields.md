# Practice details: what each item means and where to find it

The file `practice/practice.yaml` has comments explaining the format. This page explains what to ask the person and where they can find each answer.

| Item                           | Field                                                           | Where the person can find it                                                                                                                                                              |
| ------------------------------ | --------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ODS code                       | `practice.ods_code`                                             | On their NHS.UK profile, prescriptions, or ask the practice manager. One letter and five digits, for example B82005.                                                                      |
| Nation                         | `practice.nation`                                               | `england` or `wales`. The template does not yet support Scotland or Northern Ireland.                                                                                                     |
| Primary Care Network and ICB   | `practice.pcn`, `practice.icb`                                  | The practice manager will know. Optional.                                                                                                                                                 |
| Phone number and hours         | `contact.phone`, `contact.phone_hours`                          | The person. Confirm the number by asking them to read it from a letterhead or their phone system, not from memory.                                                                        |
| Email                          | `contact.email`                                                 | Optional. Only include it if the practice wants patients to email.                                                                                                                        |
| Sites and addresses            | `sites`                                                         | The person. Ask about parking and accessibility (step-free access, hearing loop, accessible toilet).                                                                                      |
| Opening hours                  | `opening_hours`                                                 | The person. Every day must be either times or `closed`. Ask about lunchtime closures and branch surgery hours.                                                                            |
| Closures                       | `closures`                                                      | Training afternoons and bank holidays.                                                                                                                                                    |
| Notices                        | `notices`                                                       | Optional short messages for the home page, with an expiry date.                                                                                                                           |
| Online consultation            | `online_services.online_consultation`                           | The provider name and the patient link. The practice can find the link in their supplier's admin settings, or by asking the supplier's support team. Some suppliers also give embed code. |
| Prescriptions and test results | `online_services.prescriptions`, `online_services.test_results` | How long prescriptions take, and how patients get results. Use the person's wording.                                                                                                      |
| Team                           | `team`                                                          | Names and roles. Only include people the practice wants listed. Ask before adding special interests or working days.                                                                      |
| Services                       | `services`                                                      | What the practice offers. Short factual descriptions only.                                                                                                                                |
| Registration area              | `registration.catchment`                                        | The practice's catchment area, in words.                                                                                                                                                  |
| Complaints                     | `complaints`                                                    | Who handles complaints and how to contact them.                                                                                                                                           |
| GP earnings (England)          | `gp_earnings`                                                   | The figures from the practice's annual GP earnings declaration. The practice manager or accountant will have them. Never estimate.                                                        |
| CQC (England)                  | `cqc.location_id`, `cqc.embed_html`                             | The CQC location ID is on the practice's page on cqc.org.uk, in the web address and page details. The CQC website also offers a rating widget the practice can copy.                      |
| Patient Participation Group    | `ppg`                                                           | Optional.                                                                                                                                                                                 |
| Accessibility statement        | `accessibility`                                                 | Use today's date for `statement_prepared` when first publishing. List any known issues.                                                                                                   |
| News                           | `news`                                                          | Optional.                                                                                                                                                                                 |
| Last reviewed date             | `site.content_last_reviewed`                                    | The date the person confirms the whole site is correct.                                                                                                                                   |

## Things to be careful about

- **Staff names:** some staff do not want their names online. Ask.
- **Old website content:** it may be out of date. Treat it as a starting point, not as confirmed.
- **NHS.UK and CQC content:** profiles and older CQC reports can be out of date. Confirm opening times and other details with the person.
- **Online consultation link:** copy it from the supplier or old site, never construct it from an ODS code or URL pattern. Ask the person to open it and confirm it is correct.
- **Embed code:** must be pasted exactly as the supplier gave it. If the check says a domain is not trusted, ask the person to confirm with their supplier before adding it.
